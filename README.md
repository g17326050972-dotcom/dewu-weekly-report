# 戴拉 · 得物经营周报

周报独立项目，包含历史周次选择、销售与售后核对结果、商品 TOP10、收藏率、得物推 ROI 和引力内容。日报由其他项目维护。

- [打开周报网站](https://dewu-weekly-report.pages.dev/)
- [下载周报项目](https://github.com/g17326050972-dotcom/dewu-weekly-report/archive/refs/heads/main.zip)

当前归档5期：2026年8月31日—9月6日、9月7—13日、9月21—27日、10月5—11日、10月12—18日。默认显示最新归档，支持下拉选择、较早/较新一期和历史指标对照，每期有固定分享链接。缺失周明确标注暂无归档。

## 文件与运行

- `site/`：可部署的完整静态周报网站。
- `weekly-archive/pages/`：各期公开页面及本地图片。
- `weekly-archive/weeks.json`：历史汇总指标、查询日期和核对口径。
- `weekly-archive/ui/`：周次选择与对照样式和脚本。
- `scripts/build-history.py`：只依赖 Python 3 标准库的生成器。

```sh
python3 scripts/build-history.py --output site
python3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

浏览器打开 http://127.0.0.1:8000/ 。可以将 `site/` 上传至静态托管服务，支持子目录部署。

## 新增一期

把审核后的公开周报及资源放入 `weekly-archive/pages/<期号>/`，在 `weeks.json` 添加对应的汇总、查询日期和核对口径，再重新生成。缺失指标填写 `null`，不能以0替代。重新采集的新周必须核验全部指标及正文，不能只改日期。

各期保留原始查询快照，后续退款和归因可能变化。9月7—13日仅剔除2笔已知关闭订单，未完成全部订单售后核对；9月21—27日、10月5—11日和10月12—18日的有效销售仍含待处理售后，均不是净利润。不同口径不可直接计算环比。

本仓库仅包含已公开的周报及汇总；不存放原始订单、客户资料、成本工作簿、登录凭据或云站点部署身份。原得物运营 SOP 仓库中的周报副本作为历史归档，本仓库是后续周报维护入口。
